# Pixeli

Landing page para una agencia de diseño web, construida con Astro, JavaScript
ES modules, Tailwind CSS y GSAP.

## Comandos

```sh
npm install
npm run dev
npm run build
```

## Estructura

- `public/`: archivos estáticos públicos, fuentes y favicon.
- `src/assets/`: espacios para imágenes, logos e iconos.
- `src/components/`: componentes de layout, secciones y UI.
- `src/data/`: tipos y colecciones de datos vacías.
- `src/layouts/`: layout base compartido.
- `src/pages/`: páginas y rutas Astro.
- `src/scripts/`: puntos de entrada preparados para scripts.
- `src/styles/`: fuentes y estilos globales con tokens de marca.
